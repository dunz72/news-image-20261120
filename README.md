All artwork is original flat illustration; no official logos or artwork are used.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=. python3 main.py
```

Writes `entry.png` (1024x1024, deterministic — two runs produce identical bytes). Without `MAKEFUN_OUTPUT_DIR` it writes to `/output/entry.png`, the harness path.
